# Code of Conduct

## The short version

Be kind. Assume good faith. Remember there's a person on the other end.

## The longer version

This project is meant to be a pleasant place to spend an afternoon. That means:

- **Be welcoming.** Beginners' questions are fine. So are questions that have
  been asked before.
- **Be direct and be kind at the same time.** Criticise the code, not the
  person who wrote it. "This will break when the file is missing" is useful;
  "this is sloppy" is not.
- **Accept that the answer is sometimes no.** Tuki is small on
  purpose, and a good idea can still be turned down for being outside the
  project's shape. [CONTRIBUTING.md](CONTRIBUTING.md) says which ideas those
  are, so the reasons should never be a surprise.
- **Don't make anyone's identity a topic.** Harassment, slurs, sexualised
  language, and personal attacks aren't welcome here, in any form, from
  anyone.

## Scope

This applies in issues, pull requests, commit messages, and anywhere else the
project is being discussed.

## Enforcement

Report anything that needs attention to [@rmpato](https://github.com/rmpato) —
by [private vulnerability report](https://github.com/rmpato/tuki/security/advisories/new)
if you'd rather it not be public, which works for conduct as well as for bugs.

The maintainer will read it, take it seriously, and keep the reporter's
identity to themselves. Responses range from a quiet word to a permanent ban,
depending on what happened.
